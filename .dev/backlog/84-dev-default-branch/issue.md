# Make dev the default branch

GitHub issue: https://github.com/4thWAIV/agent-guard/issues/84

The live GitHub issue supersedes this filing copy.

## Requested change
Make `dev` the default branch of the 4thWAIV/agent-guard GitHub repository. In local clones this remote branch is `origin/dev`.

The current GitHub default branch is `main`.

## Expected result
- GitHub's repository default branch is `dev`.
- The repository opens on `dev` by default, and new pull requests default to targeting `dev`.

## Scope
Change the default-branch setting. This issue does not request merging, deleting, or renaming branches, or changing branch protection or release policy.

Filing this issue does not change the repository setting.
