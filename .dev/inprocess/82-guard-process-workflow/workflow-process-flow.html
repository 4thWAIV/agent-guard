Completion is not a label

A factual answer closes against evidence. A code defect closes against corrected behavior and relevant verification. A human decision closes the choice; any resulting work stays assigned until verified. Rejected exceptions leave the original requirement in force.

Missing agents resume only their unfinished work. Successful results remain reusable. A new result does not erase the original input or earlier verdict.
