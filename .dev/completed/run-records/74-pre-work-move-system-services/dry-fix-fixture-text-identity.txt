# DRY-fix round — proof that fix 3 leaves every generated fixture text byte-identical
captured: 2026-09-16T19:44:36Z

Fix 3 turned SharedAnalyzerSources.EngineAssemblySource into an interpolated raw string ($$""") whose
namespace hole is {{WrongContainerNamespace}}, and rebuilt EngineInternalsOneDoorAnalyzerTests'
DecoyContainerType, DecoyContainerCreate and the SameNamedContainerInTheWrongNamespace fixture body from
that owner. The compiled string values must not move. These are the comparisons that were run, not an
assertion that they hold.

## Method
The constant values were read straight out of the two built assemblies' metadata with a throwaway tool
(System.Reflection.Metadata; PEReader + MetadataReader), so nothing is transcribed by hand and nothing
depends on reading the C# source correctly. Both assemblies were built from clean bin/obj.
