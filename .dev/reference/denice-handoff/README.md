# Handover package: the language in agent-guard, and Denice's eight planned controls

Written on 2026-11-06 for the Denice session, at Tim's instruction, from `4thWAIV/agent-guard`.

## Read these five things first

**The language has no word for any of the eight controls.** Tim is designing Denice's user-facing work model around inputs, outputs, dependencies, events, attention, workflows, steps and state machines. The language built in this repository has a word for none of them. Two have something adjacent: a dependence between two elements can be written in exactly three fixed forms, and an element can be said to *be* a process without saying anything about what is inside it. Six have nothing. No approved word writes a method's parameters or its return type. What the notation does allow is the thing to understand before reading the rest: a document may declare its own words and extend what it is written against, and `handoff/guard.yaml` already does it. So the shortage is approved vocabulary, not notation. The evidence, with every file and line, is in `02-controls-against-the-language.md`.

**EvoLang's purpose is settled, as of 2026-11-06.** EvoLang exists to describe an obligation about work: what must be true, who must make it so, under what condition, and how anyone would know it happened. Tim approved that on 2026-11-06 and said it is the entire purpose. That closes the fork between the ruling of 10 October, which said the language exists to provide the analyzer rules, the tests and the implementation plan, and the cooperative purpose of 19 October, which said it is the language in which one session asks another to do work on its behalf. They are one subject at two scales and neither is withdrawn: a test is a claim that must hold about a piece of work, and a request to another session is a claim about work to be done, with a condition on it and a party answerable for it. Because it is the entire purpose it is also a bound — every sentence EvoLang writes is a sentence about work, and a proposed word earns its place against that rather than against expressiveness. The eight controls sit inside the purpose rather than on a boundary. `05-evolang-destination.md` carries it with its sources.

**One finding worth Tim's eye before anything is built on it.** The two things the record says stopped EvoLang being written in October — a four-way union, and a reference that resolves against the vocabulary the message itself declared — and they are now half closed. The first is closed: `choice` writes a four-way union and the checker accepts one. The second is closed only partway — `link` resolves a name against everything the document reaches, but the declaration it names has to carry a value of its own, so a link can name an instance and cannot name a word. A preamble that declares words and then uses them still has nothing to resolve the second half. No document records any of this, so it is a reading of the files and not a decision, and it is his to confirm. It is set out at the end of `05-evolang-destination.md`.

**This repository records nothing about Denice.** No file, commit, issue folder or memory entry names Denice anywhere outside this package. What is known is what Tim said on 2026-11-06, which is in `00-what-tim-has-asked-for.md`.

**The current state is only in the working tree, and this is a read.** The vocabulary approved on 27 October 2026 is uncommitted, and the whole design record is untracked, so a clone or a fetch does not carry them. ## The two rules that govern any work downstream of this

Both are Tim's and both are in force. Every word of the language is approved by him, one word at a time. And no language feature is raised until a problem cannot be solved without it — so where this package reports that the language has no word for one of the eight controls, the gap is the finding, and proposing a word for it is the opposite of what is wanted.

## What is built, in one paragraph

MetaLang is the language that defines languages. A file written in it carries seven top-level keys and one ordered list of declarations; a declaration is one of seven kinds; a type is a primitive, a name, a reference to one declaration, one of five ways of holding many of a thing, or an entity with named properties; and six kinds of constraint say what a value may be. Three languages are written in MetaLang: the architecture language, which says what code is made of; the naming dictionary, which says what each of four programming languages calls each of six forms and how to find one in source; and the proposal language, which puts a decision to a reader and is itself not approved. Three real documents are written in the architecture language, describing this toolchain, the naming dictionary and the guard. Every document checks clean, the suite passes, and each document draws as a page. EvoLang — the language that would carry meaning rather than shape — has one recorded description from 2026-10-08, three unanswered design questions, its purpose settled on 2026-11-06, and not one line written.
